# Бот автомастерской

Локальный Telegram-бот на Python. Сейчас он умеет:

- регистрировать пользователя при команде `/start`;
- добавлять один или несколько автомобилей пользователя;
- показывать список добавленных автомобилей.

## Запуск

1. Установите Python 3.10 или новее.
2. В PowerShell из папки проекта создайте виртуальное окружение и установите зависимости:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Создайте бота через [@BotFather](https://t.me/BotFather), скопируйте `.env.example` в `.env` и вставьте токен:

   ```env
   BOT_TOKEN=ваш_токен
   ADMIN_ID=ваш_числовой_telegram_id
   ```

   Узнать числовой Telegram ID можно, например, через [@userinfobot](https://t.me/userinfobot).
   Бот будет полностью игнорировать сообщения всех пользователей, кроме этого ID.

4. Запустите:

   ```powershell
   python bot.py
   ```

База данных `workshop.sqlite3` создаётся автоматически в папке проекта и не попадает в Git.

## Проверка базы

После установки зависимостей запустите:

```powershell
py -m unittest -v
```
