# CRM автосервиса в Telegram

Актуальное описание компонентов, границ ИИ, принципов разработки и целевого CI/CD:
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Настройка production CI/CD: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

Локальный Telegram-бот для учёта автомобилей и заказ-нарядов. Данные хранятся в файле `workshop.sqlite3` рядом с программой.

Сейчас бот умеет:

- создавать карточки клиентов с именем и телефоном;
- привязывать автомобиль к клиенту;
- хранить автомобили клиентов, а не личные автомобили мастера;
- создавать заказ-наряд: описание работ, выручка за работы, себестоимость и продажа запчастей;
- автоматически считать прибыль по каждому заказу;
- выводить общую статистику по всем заказам.
- прикреплять к заказ-наряду фотографии работ или чеков прямо из Telegram.
- автоматически создавать и дополнять клиента, автомобиль и заказ-наряд из текста или голосового сообщения через OpenRouter;
- показывать последние заказ-наряды отдельной кнопкой.
- закрывать заказ-наряды отдельной кнопкой или произвольной фразой.
- показывать в карточке клиента телефон, автомобили, номера и число заказов в статусах «в работе»/«готов»;
- архивировать клиентов, автомобили и заказ-наряды после явного подтверждения.
- искать клиента, автомобиль или заказ по имени, телефону, госномеру или VIN;
- создавать ежедневные резервные копии SQLite-базы с хранением последних 30 дней.
- вести запись по этапам «запланирован → в работе → готов»;
- хранить причину обращения, согласованную сумму, рекомендации и историю автомобиля;
- напоминать о следующем ТО по дате или пробегу;
- архивировать записи и показывать журнал изменений по текстовому запросу;
- вечером очищать служебный диалог в Telegram, сохраняя важные карточки и фотографии.

Служебные запросы без отдельных кнопок: «покажи архив», «покажи журнал изменений»,
«клиенты, которые давно не приезжали».

Команда «очисти архив» безвозвратно удаляет архивные записи после подтверждения и
проверенного бэкапа. Автоматическая очистка удаляет записи старше 30 дней; срок
задаётся переменной `ARCHIVE_RETENTION_DAYS`.

## Запуск

1. Установите Python 3.10 или новее.
2. В PowerShell, из папки проекта, создайте виртуальное окружение и установите зависимости:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и укажите параметры:

   ```env
   BOT_TOKEN=токен_из_BotFather
   ADMIN_ID=ваш_числовой_telegram_id
   ```

   Бот принимает сообщения только от `ADMIN_ID`. Узнать свой ID можно через [@userinfobot](https://t.me/userinfobot).

4. Запустите бот:

   ```powershell
   python bot.py
   ```

## Автоматическая запись через ИИ

1. Создайте ключ на [OpenRouter](https://openrouter.ai/keys) и пополните баланс API.
2. В `.env` добавьте строку `OPENROUTER_API_KEY=ваш_секретный_ключ`.
3. Перезапустите бота.

После этого отправляйте ему обычный текст или голосовое, например: «Иван Петров, Kia Rio, замена масла, работа 1 500, масло купили за 3 200 и продали за 4 000». Бот сам создаст клиента, автомобиль и заказ-наряд, а затем покажет расчёт прибыли.

Запись можно дополнять позже, без одного фиксированного шаблона: «у Ивана телефон +7999…», «у Kia Rio пробег 126000 и VIN XTA123…», «к Kia Rio добавить фильтр: закупка 400, продажа 650», «на масле заработали 500 рублей», «покажи последние заказ-наряды».

Фраза о прямом заработке на запчастях добавляется в отдельное поле «Прибыль на запчастях» и не смешивается с оплатой работ.

## Экономия расходов OpenRouter

Бот использует отдельные модели: дешёвую текстовую — для обычных сообщений, модель речи — для голосовых, vision-модель — для будущего распознавания чеков, а продвинутую модель — только для сложных задач. Кнопка `💳 ИИ-расходы` показывает стоимость запросов за сегодня и месяц. Лимиты задаются в `.env` переменными `AI_DAILY_LIMIT_USD` и `AI_MONTHLY_LIMIT_USD`.

Для архивации можно написать: «удали клиента Иван Петров», «удали Kia Rio А123АА77» или «удали заказ 15». Бот всегда попросит подтверждение, а запись останется доступна по запросу «покажи архив».

## Резервные копии на Яндекс.Диск

Установите программу Яндекс.Диск для Windows и создайте в синхронизируемой папке каталог `ApexCRM-backups`. В `.env` укажите полный путь к нему, например:

```env
BACKUP_DIR=C:\Users\ВашеИмя\YandexDisk\ApexCRM-backups
BACKUP_RETENTION_DAYS=30
```

После перезапуска бот раз в сутки создаёт копию базы, а программа Яндекс.Диска отправляет её в облако. Бот не получает доступ к учётной записи Яндекса.

Для разбора текста по умолчанию используется `openai/gpt-4o-mini`, для речи — `openai/gpt-4o-mini-transcribe`. При необходимости замените модели в `.env` переменными `OPENROUTER_MODEL` и `OPENROUTER_TRANSCRIBE_MODEL`.

## PWA и развёртывание на VPS

Первая PWA-версия находится в `pwa.py` и `web/static`. Она предоставляет защищённую
панель с показателями за день, ближайшими записями, активными заказ-нарядами и
поиском по CRM. Веб-служба должна слушать только `127.0.0.1:8000`; внешний доступ
публикуется через HTTPS reverse proxy после подключения домена.

Systemd-службы и настройки SSH находятся в каталоге `deployment`:

- `apex-crm-bot.service` — Telegram-бот;
- `apex-crm-pwa.service` — FastAPI/Uvicorn PWA;
- `sshd-apex.conf` — вход по ключам без парольной SSH-авторизации.

Для PWA в `.env` задаются `PWA_ADMIN_USER`, `PWA_PASSWORD_HASH` и случайный
`PWA_SESSION_SECRET`. Cookie авторизации всегда помечается `Secure`, поэтому
публиковать PWA без HTTPS нельзя.

## Что добавить следующим этапом

1. Просмотр истории конкретного автомобиля и его фотографий.
2. Голосовые сообщения с локальным распознаванием речи.
3. Разбор обычного текста через API ИИ и подтверждение перед сохранением.

Подписка ChatGPT Plus не заменяет API: для автоматической работы ИИ в боте потребуется отдельный API-ключ и баланс API.
